One fortune cookie message for a software engineer, written for the
[Fortune Cookie Funnies for Engineers](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a)
bounty on make.fun.

## The fortune

> A bug you fixed last year will return tomorrow, older, wiser, and in production.

80 characters, one line.

## Run

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that is set). No network, no input data, fully deterministic.
